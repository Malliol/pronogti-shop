# pronogti-shop

Выгрузка контента со старого сайта https://pronogti-shop.ru (Tilda) для переделки сайта.
Больше нигде у клиента этих данных нет, так что эта выгрузка — единственный источник.

## Что лежит в репозитории

- `data/products.json`: все товары (60 шт.): название, цена, остаток, описание (текстом и в исходном HTML), ссылка на старый сайт, пути к фото
- `data/products.csv`: то же самое таблицей для Excel (разделитель `;`, UTF-8)
- `data/categories.json`: 7 категорий
- `images/<категория>/<uid>_<название>/01.jpg…`: фото товаров в оригинальном размере с tildacdn
- `images/site/`: картинки с главной (логотип, баннеры, обложки категорий)
- `content/*.md`: тексты страниц (главная, доставка, оферта, политика конфиденциальности, реквизиты)
- `pages/*.html`: исходный HTML страниц как есть
- `scrape.py`: скрипт выгрузки товаров (Tilda Store API), запуск: `python3 scrape.py`

## Что стоит учесть

- «База Эластик 50 гр.» на сайте без фото.
- У многих товаров всего одно фото, у серий Easy и Flame это, скорее всего, образец цвета.
- Остаток (`quantity`) пустой = на Tilda не отслеживается, `0` = нет в наличии.
- Вариантов и модификаций (размер, цвет) у товаров нет: каждый объём заведён отдельным товаром.
