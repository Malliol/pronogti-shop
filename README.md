# pronogti-shop → Kadilak Neo

Новый интернет-магазин Kadilak Neo на замену https://pronogti-shop.ru (Tilda).
Базы, топы, моделирующие гели, жидкий полигель, гель-лаки. Оренбург, доставка по России.

**Стек:** Next.js 16 (статический экспорт) + React 19 + Tailwind 4 + TypeScript. Хостинг — GitHub Pages
(`.github/workflows/deploy.yml`, деплой на каждый push в `main`).

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # → out/
npm run catalog    # пересобрать каталог и фото из data/products.json
```

## Как устроено

- `design/` — макет от дизайнера (HTML-прототип + README с токенами). Главная — вариант C.
- `src/app/` — страницы: `/`, `/catalog/`, `/catalog/<cat>/`, `/product/<slug>/?c=<оттенок>`, `/quiz/`,
  `/delivery/`, `/checkout/`, `/order/`, `/privacy/`, `/rec/`, `/oferta/`.
- `src/data/catalog.json` + `public/img/` — генерируются `scripts/build-catalog.mjs` из выгрузки, коммитятся.
  Серии («Гель Easy N 1…11», полигель, гель-лаки) склеены в один товар с оттенками; у каждого оттенка
  своя цена, остаток и фото. Правила склейки — `FAMILIES` в скрипте.
- Свотчи оттенков — кроп первого фото (HEX-цветов у магазина нет).
- Корзина — `localStorage['kn-cart']`, тема — `localStorage['kn-theme']` (или `?theme=dark`).

## Выгрузка старого сайта

- `data/products.json` / `data/products.csv` — все 60 позиций: цены, остатки, описания, фото
- `images/<категория>/…` — оригиналы фото с tildacdn, `images/site/` — картинки с главной
- `content/*.md` — тексты страниц (доставка, оферта, политика, реквизиты)
- `scraper/` — скрипт выгрузки (Tilda Store API) и исходный HTML
