# Handoff: интернет-магазин Kadilak Neo

## Обзор
Новый интернет-магазин материалов для маникюра (базы, топы, моделирующие гели, полигель, гель-лаки, расходники) взамен текущего сайта pronogti-shop.ru (Tilda). Бренд — **Kadilak Neo**. Аудитория: мастера маникюра и покупательницы для домашнего маникюра. Город — Оренбург, доставка по России (СДЭК, Почта России), дублирование продаж на маркетплейсах (Ozon, Wildberries, Авито, Яндекс Маркет).

## О файлах
Файлы в этом пакете — **дизайн-референсы в HTML**: прототипы, показывающие внешний вид и поведение. Это не production-код. Задача — **воссоздать дизайн в целевом стеке** проекта (React/Next.js, Vue/Nuxt и т.д.) по его устоявшимся паттернам. Если стека ещё нет — рекомендуется Next.js (SSR/SEO для каталога) + headless-CMS или админка для товаров + платёжный провайдер (ЮKassa / CloudPayments / Tinkoff) + API СДЭК и Почты России для расчёта доставки.

Открыть прототип: `PRONOGTI Shop.dc.html` в браузере (нужен локальный сервер, например `npx serve .`). Мобильная версия в двух рамках телефона: `Kadilak Neo Mobile.dc.html`.

## Точность
**High-fidelity.** Цвета, типографика, отступы и взаимодействия финальные. **Контент-заглушки:** цены, описания товаров, названия/HEX оттенков, состав наборов подбора — придуманы, их нужно заменить реальными данными. Фото товаров — пустые слоты.

## Взаимодействия и поведение
- SPA-навигация между экранами со скроллом наверх; в продакшене — реальные маршруты: `/`, `/catalog`, `/catalog/:category`, `/product/:slug?color=:id`, `/quiz`, `/delivery`, `/checkout`, `/order/:id`.
- Переходы и анимации минимальные: hover-изменения границы/фона, сдвиг свотча палитры −2px. Длительности не заданы — использовать 120–160ms ease-out.
- Фокус: `:focus-visible { outline: 2px solid var(--color-accent); outline-offset: 2px }` (из дизайн-системы).
- Тема: переключатель в шапке, выбор хранится в `localStorage['kn-theme']`, по умолчанию светлая; `?theme=dark|light` в URL переопределяет. Реализация — `data-theme` на `<html>` + переопределение CSS-переменных.
- Ссылки маркетплейсов сейчас ведут на **поиск** по «Kadilak Neo + название + объём». В продакшене — поле с прямой ссылкой на карточку для каждой площадки у каждого товара; кнопку скрывать, если ссылки нет.
